## Code for the paper 'Modelling Crop Phenology in Data Scarce Regions Using Transfer Learning'

Data preparation is in the folder 'process_based/data_preparation'. The finished processed data is in the folder 'results_for_comparing'.

Results Sections 3.1 and 3.2 are in the folder 'process_based'. The main code for the calibration and evaluation are 'process_based/parameter_calibration_model_evaluation/DE_calibration_pb_31_32.ipynb' and 'SSA_calibration_pb_31_32_34.ipynb'.

Results Sections 3.3 and 3.4 are in the folder 'ML'.
